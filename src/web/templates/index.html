📢 Boshqaruv Telegram Kanali (Talab 16)

Asosiy Bildirishnoma

Har safar yangi talaba to'garakka a'zo bo'lganda ushbu Telegram kanalga avtomatik tarzda talabaning barcha ma'lumotlari (F.I.Sh, fakultet, yo'nalish, kurs, telefon, username) yuboriladi.

Qanday ulanadi?
1. Telegramda universitet ma'murlari uchun kanal yoki guruh oching.
2. Botingizni ushbu kanalga a'zo qilib, unga Administrator (Xabarlar yozish) huquqini bering.
3. Kanal linkini (masalan: @iqtidorli_boshqaruv) yoki ID sini pastga kiriting.

👤 Shaxsiy Admin Telegram ID

Kanalga qo'shimcha ravishda o'z shaxsiy Telegramingizga ham arizalar kelishini istasangiz, Telegram Chat ID'ingizni kiriting. (O'z Telegram ID'ingizni bilish uchun @userinfobot ga /start yuboring).
